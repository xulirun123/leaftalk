# 聊天内容搜索功能说明

## 📋 功能概述

全新的聊天内容搜索功能，仿照微信的搜索界面设计，支持多种分类搜索方式。

## 🎨 界面设计

### 主搜索页面 (`/chat-search/:chatId?`)

**布局特点：**
- ✅ 无顶部导航栏，只有状态栏（25px）
- ✅ 搜索框在状态栏下方，右侧有"取消"按钮
- ✅ 快速搜索分类按钮（3列网格布局）

**快速搜索分类：**
1. 📅 日期 - 按日期查找
2. 🖼️ 图片 - 图片搜索
3. 🎵 音乐 - 音乐搜索
4. 📄 文件 - 文件搜索
5. 🔗 链接 - 链接搜索
6. 🎬 视频 - 视频搜索
7. 💰 交易 - 红包/转账交易记录
8. 📦 小程序 - 小程序搜索
9. 📺 视频号 - 视频号搜索

### 分类搜索页面

**共同特点：**
- ✅ 无顶部导航栏，只有状态栏
- ✅ 搜索框内有固定前缀文本（如"文件"、"图片"等）
- ✅ 搜索框右侧有"取消"按钮
- ✅ 支持模糊搜索

**特殊页面：**

#### 1. 日期搜索页面 (`/chat-search-date/:chatId?`)
- ✅ 有顶部导航栏（标题：按日期查找）
- ✅ 日期选择器（开始日期、结束日期）
- ✅ 快速选择按钮（今天、昨天、最近一周、最近一月、最近三月、最近一年）
- ✅ 显示搜索结果列表

#### 2. 图片搜索页面 (`/chat-search-image/:chatId?`)
- ✅ 3列网格布局显示图片
- ✅ 图片悬停显示来源信息
- ✅ 点击图片可预览

#### 3. 文件搜索页面 (`/chat-search-file/:chatId?`)
- ✅ 列表显示文件
- ✅ 显示文件名、大小、来源、时间
- ✅ 支持文件名模糊搜索
- ✅ 高亮显示搜索关键词

#### 4. 其他分类搜索页面
- 链接、音乐、视频、交易、小程序、视频号
- 目前复用文件搜索页面的布局
- 后续可根据需要定制各自的显示样式

## 🛣️ 路由配置

```javascript
// 主搜索页面
/chat-search/:chatId?

// 分类搜索页面
/chat-search-date/:chatId?       // 日期搜索
/chat-search-image/:chatId?      // 图片搜索
/chat-search-file/:chatId?       // 文件搜索
/chat-search-link/:chatId?       // 链接搜索
/chat-search-music/:chatId?      // 音乐搜索
/chat-search-video/:chatId?      // 视频搜索
/chat-search-transaction/:chatId?  // 交易搜索
/chat-search-miniprogram/:chatId?  // 小程序搜索
/chat-search-videochannel/:chatId? // 视频号搜索
```

**参数说明：**
- `chatId` 为可选参数
- 如果提供 `chatId`，则只搜索该聊天的内容
- 如果不提供 `chatId`，则搜索所有聊天的内容

## 📱 使用方式

### 1. 从聊天详情页进入
```javascript
// ChatInfo.vue
const searchHistory = () => {
  const chatId = route.params.id as string
  router.push(`/chat-search/${chatId}`)
}
```

### 2. 从全局搜索进入
```javascript
router.push('/chat-search')
```

### 3. 直接跳转到分类搜索
```javascript
// 搜索所有聊天的文件
router.push('/chat-search-file')

// 搜索特定聊天的文件
router.push('/chat-search-file/chat_15_2')
```

## 🎯 核心功能

### 1. 关键词搜索
- 支持搜索消息内容、聊天名称、发送者名称
- 实时搜索，输入即搜索
- 关键词高亮显示

### 2. 分类筛选
- 9种快速分类入口
- 每种分类有专门的搜索页面
- 支持按聊天ID筛选

### 3. 日期筛选
- 自定义日期范围
- 快速选择时间段
- 显示时间段内的所有消息

### 4. 搜索结果展示
- 显示消息来源（聊天名称）
- 显示发送者（群聊时）
- 显示消息时间
- 点击跳转到具体消息

## 🔄 数据流

### 1. 搜索流程
```
用户输入关键词
  ↓
触发搜索（实时）
  ↓
过滤搜索结果
  ↓
按chatId筛选（如果有）
  ↓
显示结果列表
```

### 2. 分类跳转流程
```
点击分类按钮
  ↓
获取当前chatId（如果有）
  ↓
构建目标路径
  ↓
跳转到分类搜索页面
```
