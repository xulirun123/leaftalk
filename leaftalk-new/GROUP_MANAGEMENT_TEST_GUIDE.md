## 故障排查

### 问题 1: 开关状态仍然恢复到默认值

**可能原因**:
- 页面没有被缓存
- `onActivated` 钩子没有被触发

**检查方法**:
1. 打开开发者工具 → Network 标签
2. 切换页面时，检查是否有新的 API 请求
3. 如果没有新请求，说明页面被重新创建了

**解决方法**:
```bash
# 清除浏览器缓存
Ctrl + Shift + Delete

# 或者硬刷新
Ctrl + Shift + R
```

### 问题 2: 控制台显示错误信息

**可能原因**:
- 后端 API 返回错误
- 用户权限不足
- 网络连接问题

**检查方法**:
1. 查看控制台的完整错误信息
2. 检查 Network 标签中的 API 响应
3. 确认用户是群主或管理员

### 问题 3: 开关状态与后端不同步

**可能原因**:
- 数据库中的设置没有正确保存
- 页面加载时没有获取最新数据

**检查方法**:
1. 刷新页面，检查开关状态是否正确
2. 查看后端日志，确认 API 调用是否成功
3. 检查数据库中的 `groups` 表

## 性能检查

### 内存占用
- 打开开发者工具 → Performance 标签
- 切换页面多次，观察内存是否持续增长
- ✅ 正常情况下，内存应该保持稳定

### 页面加载时间
- 第一次加载: ~500ms（包括 API 调用）
- 返回时加载: ~100ms（从缓存恢复 + 重新加载数据）
