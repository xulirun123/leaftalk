## 🔧 后端 API

### GET /api/groups/{groupId}/join-requests
获取邀请进群申请列表

**响应**:
```json
{
  "success": true,
  "data": [
    {
      "id": "req_123",
      "user_id": 15,
      "nickname": "用户昵称",
      "remark": "备注（优先显示）",
      "avatar": "头像URL",
      "status": "pending",
      "created_at": "2025-10-18T10:00:00Z"
    }
  ]
}
```

### PUT /api/groups/{groupId}/join-requests/{requestId}
处理邀请进群申请

**请求体**:
```json
{
  "action": "approve" 或 "reject"
}
```
