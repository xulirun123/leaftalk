# 群主判断功能测试指南

## 🎯 测试目标

验证创建群聊的用户能够正确识别为群主，并显示"删除"按钮和"群管理"项。

## 📋 前置条件

1. **后端 API 已实现**
   - `GET /api/groups/{groupId}` - 返回 `creatorId` 字段
   - `GET /api/groups/{groupId}/members` - 返回成员的 `role` 字段
   - `GET /api/users/batch?ids={userIds}` - 返回用户详细信息

2. **前端代码已更新**
   - `src/modules/chat/pages/GroupInfo.vue` - 已应用所有修改

3. **开发服务器正在运行**
   - 前端: http://localhost:5173
   - 后端: http://localhost:8893

## 🔍 调试技巧

### 1. 查看浏览器控制台日志

打开浏览器开发者工具（F12），查看 Console 标签页：

```
📋 群组详细信息: { ... }
✅ 通过 creatorId 判断为群主
👤 当前用户信息: { ... }
👤 是否是群成员: true
👑 是否是群主: true
```

### 2. 检查网络请求

在 Network 标签页查看以下 API 请求：

- `GET /api/groups/{groupId}` - 检查响应中是否包含 `creatorId`
- `GET /api/groups/{groupId}/members` - 检查响应中是否包含 `role` 字段
- `GET /api/users/batch?ids={userIds}` - 检查响应中是否包含用户信息

### 3. 检查 Vue 组件状态

在浏览器开发者工具中安装 Vue DevTools 扩展，查看组件状态：

- `groupInfo.creatorId` - 应该等于群主的用户ID
- `currentUserRole` - 应该是 'owner'、'creator'、'admin' 或 'member'
- `isGroupOwner` - 应该是 true（对于群主）或 false（对于非群主）

## ⚠️ 常见问题

### 问题 1: 看不到"删除"按钮

**可能原因**:
1. 后端没有返回 `creatorId` 字段
2. 后端返回的 `creatorId` 与当前用户ID不匹配
3. 后端返回的成员 `role` 不是 'owner' 或 'creator'

**解决方案**:
1. 检查浏览器控制台日志中的 `creatorId` 值
2. 检查网络请求中的 API 响应
3. 确认后端 API 实现正确

### 问题 2: 非群主也能看到"删除"按钮

**可能原因**:
1. `isGroupOwner` 计算属性有问题
2. 后端返回的 `creatorId` 错误

**解决方案**:
1. 检查浏览器控制台日志中的 `isGroupOwner` 值
2. 检查网络请求中的 API 响应
3. 查看 Vue DevTools 中的组件状态

### 问题 3: 群成员头像显示不正确

**可能原因**:
1. 后端 `/api/users/batch` 接口没有实现
2. 后端返回的用户信息格式不正确

**解决方案**:
1. 检查网络请求中的 `/api/users/batch` 响应
2. 确认后端返回的用户信息包含 `nickname` 和 `avatar` 字段
