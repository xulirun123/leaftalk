# 群聊信息页面测试指南

## 🎯 测试目标

验证群聊信息页面的以下功能：
1. ✅ 显示真实用户头像
2. ✅ 显示真实用户昵称
3. ✅ 移除群聊按钮（仅群主可见）
4. ✅ 删除群聊功能

## 📋 前置条件

1. **后端服务运行**: 确保后端服务在 `http://localhost:8893` 运行
2. **前端服务运行**: 确保前端服务在 `http://127.0.0.1:5173` 运行
3. **已登录**: 使用有效的用户账号登录
4. **存在群聊**: 至少有一个群聊存在

## 🧪 测试步骤

### 测试 1: 验证真实头像和昵称显示

**步骤**:
1. 打开应用，进入聊天列表
2. 点击任意群聊进入聊天页面
3. 点击右上角的群聊信息按钮（或点击群聊名称）
4. 进入群聊信息页面

**预期结果**:
- ✅ 群成员头像区域显示成员头像
- ✅ 每个头像下方显示成员昵称（不是"用户ID"）
- ✅ 头像应该是真实的用户头像（不是生成的默认头像）

**浏览器控制台日志**:
```
🔄 获取成员的真实用户信息...
✅ 获取用户信息成功，用户数: X
👤 更新成员信息: { id: 1, oldName: "用户1", newName: "张三", avatar: "..." }
```

### 测试 2: 验证移除群聊按钮

**前置条件**:
- 当前用户是群主

**步骤**:
1. 进入群聊信息页面
2. 查看群成员头像区域

**预期结果**:
- ✅ 如果当前用户是群主，应该看到"删除"按钮（红色垃圾桶图标）
- ✅ 如果当前用户不是群主，不应该看到"删除"按钮

### 测试 3: 验证删除群聊功能

**前置条件**:
- 当前用户是群主
- 已看到"删除"按钮

**步骤**:
1. 点击"删除"按钮
2. 确认对话框出现
3. 点击"删除"按钮确认

**预期结果**:
- ✅ 确认对话框出现，提示"删除群聊后，所有成员都将无法访问此群聊，确定要删除吗？"
- ✅ 点击"删除"后，群聊被删除
- ✅ 页面自动跳转到聊天列表
- ✅ 聊天列表中不再显示该群聊

**浏览器控制台日志**:
```
显示删除群聊对话框
🗑️ 删除群聊: group_xxx
✅ 删除群聊成功
```

### 测试 4: 验证其他功能按钮

**步骤**:
1. 进入群聊信息页面
2. 查看群成员头像区域下方的功能按钮

**预期结果**:
- ✅ "邀请"按钮：所有成员都可见
- ✅ "移除"按钮：仅群主和管理员可见
- ✅ "删除"按钮：仅群主可见

### 测试 5: 验证群聊设置功能

**步骤**:
1. 进入群聊信息页面
2. 向下滚动查看功能列表

**预期结果**:
- ✅ 群聊名称：可编辑
- ✅ 群公告：仅群主可编辑
- ✅ 群管理：仅群主可见
- ✅ 邀请申请：仅群主和管理员可见
- ✅ 群二维码：所有成员可见
- ✅ 群备注：所有成员可编辑
- ✅ 我在本群的昵称：所有成员可编辑

## 🔍 调试技巧

### 打开浏览器开发者工具

1. 按 `F12` 打开开发者工具
2. 切换到 "Console" 标签
3. 查看日志输出

### 查看网络请求

1. 打开开发者工具
2. 切换到 "Network" 标签
3. 刷新页面
4. 查看 `/api/users/batch` 请求
5. 检查响应数据

### 常见问题

**问题 1: 头像显示为默认生成头像**
- 原因：后端 `/api/users/batch` 接口未实现或返回错误
- 解决：检查浏览器控制台是否有错误日志
- 日志：`⚠️ 获取用户信息失败，使用本地数据`

**问题 2: 昵称显示为"用户ID"**
- 原因：用户信息中没有昵称字段
- 解决：检查后端返回的用户数据是否包含 `nickname` 或 `username` 字段

**问题 3: 删除按钮不显示**
- 原因：当前用户不是群主
- 解决：使用群主账号登录

**问题 4: 删除群聊后页面没有跳转**
- 原因：后端删除失败或返回错误
- 解决：检查浏览器控制台错误日志
